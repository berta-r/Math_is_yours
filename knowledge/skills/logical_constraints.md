title: Logical constraints

Find possibilities satisfying all conditions and check counterexamples.

## Common difficulty
Using one condition while forgetting another.

## Hint strategy
Rewrite each condition as a separate check.

## Hints
- Rewrite each condition as a separate check.
- Try a small candidate and test it against every condition.
- Cross out a candidate only when you can name the condition it breaks.
