Use equal groups and repeated addition to find a total.

## Common difficulty
Confusing the number of groups with the number in each group.

## Hint strategy
Find the equal groups in the problem.

## Hints
- Find the equal groups in the problem.
- Write the number of groups and the size of each group separately.
- Use repeated addition to check your multiplication.
